## Tasks (each: failing test → code → green → gates)

1. **control** — `tests/exec/test_control.py`: CancelledError, registered type, any class named
   `GraphBubbleUp` in the MRO; bad registration → `ToolUsageError`; `first_error` unwraps.
2. **retry** — `tests/exec/test_retry.py`: `Backoff.delay` maths (jitter, cap, attempt ≥ 1);
   retry rule table; attempt loop: retries count, delays via `FakeClock`, timeout →
   `ToolTimeout`, control flow never retried.
3. **guards** — `tests/exec/test_guards.py`: `once_per_run`, `max_calls`, distinct call ids
   (re-entry not counted), eviction keeps active runs, RW lock exclusivity + FIFO,
   cancellation while waiting, nested calls bypass, `per_kind` caps.
4. **pipeline** — `tests/exec/test_pipeline_*.py`: step order with a recording hook; not
   found; args invalid; short-circuit (attempts 0, no cache store); approval (pre-approval,
   confirm callable, no port → denied + WARNING, denied, pending, edited args re-validated,
   rule error); cache hit / miss / broken / unencodable; retries and timeouts; on_tool_error
   recovery; after_tool replacement; ledger entry fields; events vs `REQUIRED_DATA`;
   `run_id == ""` → fresh run per call.
5. **batches** — `tests/exec/test_batch.py`: input order; collect vs fail_fast (siblings
   cancelled, first error unwrapped); pending in collect; control flow unwrapped from every
   batch method; non-parallel-safe batch runs one at a time; `as_completed` completion
   order and early exit cancels the rest.
6. **plan** — `tests/exec/test_plan.py`: validation problems listed together; waves with a
   recording tool; callable args see only their deps; dependency-failed; fail_fast.
7. **parallel** — `tests/exec/test_parallel.py`: order, timeout per item, retries with
   backoff, awaitable + retries → `ToolUsageError`, collect keeps exceptions in place.
8. **executor facade** — `tests/exec/test_executor.py`: `context`, `run_scope` events +
   `end_run`, `registry=` override, `replace` (no mutation, shared run state), nested call
   in a non-parallel-safe tool (I6), two concurrent `run_sync` calls (B6), approval resume
   keeps guards (B5).
9. **defaults** — `tests/exec/test_defaults.py`: lazy singleton, setter type check, `runner_for`.
10. **docs + example** — `docs/concepts/executor.md` (mermaid, ≤150 lines),
    `examples/executor.py` + `tests/exec/test_example_executor.py`; `docs/concepts/tools.md`
    policy table now enforced; `SHARED-EDITS.md` (exports, nav, features rows, CHANGELOG).
