## Design notes

- Every `mcp` import is lazy (§2.3 R6); `annotations.py` is pure dict logic.
- MCP has a native tool-error channel: every `Exception` becomes `CallToolResult(is_error=True)`
  with `ErrorInfo.message` (foreign messages never leak) and `_meta`
  `agent-adapter/error_kind`; an unknown or non-exported tool is a protocol error
  (`INVALID_PARAMS`). Control flow (`CancelledError`, `GraphBubbleUp`) propagates.
- Call ids: MCP has none of its own; `_meta["agent-adapter/call_id"]` (and `run_id`, or
  the `X-Run-Id` header) let a client resume a pending approval. The pending result
  returns all three ids in `_meta`.
- Client approval is opt-in: the default keeps approval in Python (executor port).
