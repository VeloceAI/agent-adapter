# WP19 — TypeScript client: TDD plan

Contract: §15.2 routes, §15.3 payloads, §15.4 problems, §16 client. Package
`@agent-adapter/client` in `clients/typescript/`, zero runtime dependencies, Node ≥ 20.

## Files

| File | Role |
|---|---|
| `package.json`, `tsconfig.json`, `tsdown.config.ts`, `package-lock.json` | package, strict type check, ESM + CJS build |
| `src/types.ts` | §15.3 payloads, `Problem`, `LedgerSummary`, `ClientOptions`, `RunEvent` |
| `src/errors.ts` | `ToolServerError` + one subclass per §15.4 kind family; transport and protocol errors |
| `src/http.ts` | one request: auth header, per-attempt timeout, signal linking, retry policy, problem parsing |
| `src/sse.ts` | WHATWG SSE parser: split frames, CR/LF/CRLF, comments, BOM, bounded buffer |
| `src/client.ts` | `ToolClient` (every §16 method) |
| `src/adapters.ts` | `toolDefinitions`, `asVercelTools` |
| `src/index.ts` | re-exports |
| `examples/*.ts` | doc snippets, run by the test suite |
| `test/*.test.ts` | `node --test`, fetch mocked; `live.test.ts` runs only with `AA_BASE_URL` (MC gate) |
| `docs/cross-language/typescript-client.md` | user page |

## Tasks (each: failing test first, then code)

1. Scaffold package + `test/helpers.ts` (scripted fake fetch, SSE body builder).
2. Errors: problem body → class by kind, then by status; non-problem → `about:blank`.
3. HTTP: bearer token (string / sync / async fn), user headers, timeout → `ToolTransportError`,
   user abort → the signal's reason, retry: GETs on network / 408 / 429 / 502 / 503 / 504,
   POSTs only on connect-phase failures and 429 / 503 with `Retry-After`; Retry-After
   seconds and HTTP-date honoured, capped; bounded attempts.
4. Client methods: `listTools` (shape, tags, kinds query), `getTool`, `invoke` (200 / 202,
   body run_id/thread_id, Idempotency-Key generated once, stable across retries), approvals
   (`getApproval`, `listApprovals`, `decide` ok / denied), `cost`, URL encoding, base prefix.
5. SSE: frames split at every byte, CRLF / CR, comments, multi-line data, `id`, `retry`,
   oversize line → `EventStreamError`; `events()` with `close_on`, `Last-Event-ID`, stop on
   `end`, reconnect after a drop from the last id (bounded), cancel on `break` / abort.
6. Adapters: `toolDefinitions` execute → result / `{pending_approval}`; `asVercelTools`.
7. Examples + docs page; README.
8. Online: `npm install` (lockfile), `tsc`, `tsdown`, `publint`, `attw --pack .`.

## Exit gate

`node --test test/` green offline; `tsc --noEmit` clean; `ts-build` (npm ci, tsdown, publint,
attw) clean; `mkdocs build --strict` clean.
