Chat with your agent

This viewer was started without an agent, so there is nothing to chat with.

Start it with one. The chat then sits next to the run's graph, timeline, events, state and cost:

agent-adapter ui --agent app:chat
agent-adapter ui --model app:model --tools app:registry

Or from Python: from agent_adapter.viewer import serve; serve(agent=chat)
